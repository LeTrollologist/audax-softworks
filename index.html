About Audax

Audax (adj.) — bold, daring.

Audax Softworks is the studio behind reactive client websites like Aristos Property Works and Numa's Space, developer tools like Orion Editor and WebSage, and indie software spanning games, Discord plugins, and network utilities.

We believe the best software is opinionated, performant, and built with the smallest stack that gets the job done right.

  • Client & personal web experiences
  • AI-assisted developer tooling
  • Indie games & simulations
  • Discord plugins & desktop utilities
