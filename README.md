# Audax Softworks

Company portfolio site for **Audax Softworks** — a lean, reactive showcase of client sites, developer tools, games, and systems software.

**Stack:** Vanilla HTML · CSS · JavaScript (zero build step)

## Preview locally

Open `index.html` in your browser, or serve with any static server:

```bash
npx serve .
# or
python -m http.server 8080
```

## Deploy to GitHub Pages

1. Create a new public repo on GitHub: `audax-softworks`
2. Push this folder:

```bash
cd audax-softworks
git init
git add .
git commit -m "Initial Audax Softworks portfolio site"
git branch -M main
git remote add origin https://github.com/LeTrollologist/audax-softworks.git
git push -u origin main
```

3. In GitHub → **Settings → Pages** → Source: **Deploy from branch** → `main` / `/ (root)`
4. Your site will be live at: `https://letrollologist.github.io/audax-softworks/`
